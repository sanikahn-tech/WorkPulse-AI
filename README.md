WorkPulse AI — Workflow SLA Risk Prediction

Overview:

WorkPulse AI is a machine learning prototype that estimates the risk of Service Level Agreement (SLA) breaches in workflow requests.

The project uses Python and Scikit-learn to build a classification model and provides an interactive interface for predicting SLA breach risk.

Note: This project uses synthetic data for demonstration. Its predictions have not been validated on real-world company workflow data.

Features:

Synthetic workflow dataset generation,
Data preprocessing and feature encoding,
Logistic Regression classification,
Model evaluation using precision, recall, F1-score, ROC-AUC, and a confusion matrix,
Interactive risk prediction using ipywidgets,
Export of the trained model and generated dataset,
Technologies Used,
Python,
Pandas and NumPy,
Scikit-learn,
Matplotlib and Seaborn,
Google Colab / Jupyter Notebook,
ipywidgets,
Joblib.

Installation and Usage:

Open the notebook in Google Colab.

Run the cells in order.

The notebook generates synthetic data, trains the model, evaluates its performance, and provides an interactive prediction interface.

Model Evaluation:

The notebook displays classification metrics and a confusion matrix. Add the actual results from your executed notebook here.

Limitations:

The dataset is synthetically generated.

Performance on synthetic data does not establish accuracy on real-world workflows.

Real-world use requires validation on appropriate historical data.
